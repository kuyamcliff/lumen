DRM

One configuration covers Widevine, PlayReady and FairPlay, and is translated for whichever pipeline ends up playing the stream.

player.drm = {
  widevine:  { licenseUrl: "https://license.example/wv" },
  playready: { licenseUrl: "https://license.example/pr" },
  fairplay:  {
    licenseUrl: "https://license.example/fps",
    certificateUrl: "https://license.example/fps-cert",
  },
};

await player.load("https://example.com/protected.m3u8");
Name every key system you support. Only one is available on any given platform — FairPlay on Apple devices, Widevine on Chrome and Firefox, PlayReady on Edge — and Lumen picks whichever the browser actually offers.

Authenticated licenses

player.drm = {
  widevine: {
    licenseUrl: "https://license.example/wv",
    headers: { Authorization: `Bearer ${token}` },
  },
};

Custom license handling

Some license servers wrap the response, or expect a transformed request. transformLicense runs before the response reaches the CDM:

player.drm = {
  widevine: {
    licenseUrl: "https://license.example/wv",
    transformLicense: async (response) => {
      const { license } = JSON.parse(new TextDecoder().decode(response));
      return Uint8Array.from(atob(license), (c) => c.charCodeAt(0)).buffer;
    },
  },
};

Failures

A device that can't unlock the stream gets a plain-language message rather than an EME exception:

player.on("error", ({ message }) => show(message));
// "This video is protected and couldn't be unlocked on this device."
