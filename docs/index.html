Lumen

A web-first video player built as a native Web Component. One tag plays MP4, MOV, MKV, WebM, Ogg, FLV, MPEG-TS, HLS and DASH — including formats no browser supports on its own — from a core under 26 kB gzipped.

25.7 kB core, gzipped 0 required dependencies MIT licensed Works in any framework 
<script type="module" src="https://unpkg.com/@lumen/player"></script>

<lumen-player src="movie.mkv"></lumen-player>

That's the whole integration. No configuration, no build step, no framework — and the file above is a Matroska file, which no browser can play by itself.

What makes it different

It plays what other players won't

"Format not supported" has two independent causes: the container can't be parsed, or the codec can't be decoded. Most players conflate them and give up. Containers are only packaging, so Lumen rebuilds them in JavaScript — an MKV is demuxed and rewritten as fragmented MP4 with the compressed frames copied across untouched. No transcoding, no WASM decoder, no quality loss.

Read about format support →

It degrades in useful steps

When something can't work, Lumen asks what still can. An undecodable audio track (AC-3, DTS — the usual reason an MKV "won't play") is dropped so the video still plays, and the viewer is told why. A truncated upload plays up to the point it was cut off. A genuinely impossible file gets a sentence a human can act on, never a raw MediaError.

It stays small

Every heavy capability — the MKV and FLV remuxers, the HLS and DASH engines, ads, the framework wrappers — is a separate chunk loaded on demand. A page that shows an MP4 downloads the MP4 player, and nothing else. The size budget is enforced in CI.

It's a real Web Component

Not a React component with a wrapper for everyone else. It works in plain HTML, and in React, Vue and Svelte through thin official bindings.
