Translation

Every control label, menu entry, screen-reader announcement and error message resolves through one string table.

player.setTranslations({
  play: "Lecture",
  pause: "Pause",
  settings: "Réglages",
  quality: "Qualité",
  captions: "Sous-titres",
  fullscreen: "Plein écran",
});
Any key you leave out keeps its English default, so a partial translation degrades to mixed language rather than blank buttons.

Full key list

The authoritative list is the LumenStrings interface. Keys fall into four groups:

  • Controls — play, pause, mute, unmute, volume, seek, fullscreen, exitFullscreen, pictureInPicture, cast, next, previous, settings, captions
  • Menus — speed, normalSpeed, quality, audio, chapters, appearance, auto, off, back
  • Caption styling — subtitleSize, subtitleBackground, subtitleEdge, subtitlePosition, small, medium, large, solid, dropShadow, outline, none, bottom, top
  • Announcements — templates with a {value} placeholder, e.g. qualityAnnouncement: "Quality: {value}"
import { DEFAULT_STRINGS } from "@lumen/player";
console.log(Object.keys(DEFAULT_STRINGS));  // every key

Right-to-left

Set dir="rtl" on the element or any ancestor; the control bar follows the document's writing direction.
