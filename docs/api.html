Presentation

player.requestFullscreen(): Promise<void>

player.requestPictureInPicture(): Promise<PictureInPictureWindow>
player.isCastAvailable: boolean
player.requestCast(): Promise<boolean>

requestFullscreen() covers the prefixed WebKit spelling and the iPhone case, where the Fullscreen API doesn't exist on elements at all and the video itself has to be promoted to the system player. It always returns a promise — including where nothing is supported, so a .catch() is enough to handle every outcome.
