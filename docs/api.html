API reference

Attributes

AttributeMeaning
srcMedia URL
posterPoster image
autoplay, loop, mutedAs native <video>
preloadnone | metadata | auto
crossoriginMirrored onto the underlying video element
themedark | light | system
aspect-ratioe.g. 16/9
object-fitcontain | cover
thumbnailsWebVTT sprite sheet for scrub previews
chaptersWebVTT chapters file
resumeSet to off to stop remembering playback positions

Playback

player.play(): Promise<void>
player.pause(): void
player.seek(time: number): void
player.load(src: string | LumenSource | LumenSource[]): Promise<void>
player.destroy(): void

player.currentTime: number      // read/write
player.duration: number
player.paused: boolean
player.ended: boolean
player.volume: number           // read/write, 0-1
player.muted: boolean           // read/write
player.playbackRate: number     // read/write
player.videoElement: HTMLVideoElement
