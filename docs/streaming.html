HLS & DASH

Adaptive streaming works the same way for both: point the player at a manifest and the quality menu populates itself.

HLS

<lumen-player src="https://example.com/stream.m3u8"></lumen-player>

Safari plays HLS natively. Everywhere else Lumen loads hls.js on demand — install it, or include it via a script tag for plain HTML pages.

DASH

<lumen-player src="https://example.com/manifest.mpd"></lumen-player>

Requires dashjs, loaded the same lazy way.

Quality selection

player.qualityLevels;        // LumenQualityLevel[]
player.currentQuality;       // the active level, or null on auto
player.setQuality("auto");   // let ABR decide
player.setQuality(3);        // pin to a level id

player.on("qualitieschange", ({ levels }) => console.log(levels));
player.on("qualitychange", ({ level, auto }) => console.log(level, auto));

The settings menu exposes the same list, with the active level marked and an Auto entry showing what ABR currently picked.

Audio tracks

Multi-language streams expose their audio renditions through one normalized API, whether they come from HLS, DASH, the native element, or a remuxed MKV:

player.audioTracks;          // [{ id, label, language, active }]
player.setAudioTrack("fr");

player.on("audiotrackchange", ({ track }) => console.log(track));

Raw MPEG-TS

A bare .ts file plays through hls.js's transport-stream transmuxer — Lumen hands it a one-entry playlist rather than duplicating a TS demuxer.
