Ads

VAST 2–4 linear ads — pre-roll, mid-roll and post-roll — as an optional plugin that isn't in the core bundle.

import { ads } from "@lumen/player/plugins/ads";

player.use(ads({ tagUrl: "https://ads.example/vast.xml" }));

Scheduling breaks

player.use(ads({
  breaks: [
    { offset: "pre",  tagUrl: "https://ads.example/pre.xml" },
    { offset: 300,    tagUrl: "https://ads.example/mid.xml" },  // 5 minutes in
    { offset: "post", tagUrl: "https://ads.example/post.xml" },
  ],
}));

How it plays

Ads play in a separate video element stacked over the player, rather than by swapping the content source. That keeps the content's buffer, position and decoder state untouched, so returning from an ad is instant instead of a re-buffer — and a broken ad can never corrupt the content's playback state.

An ad that fails to load, times out, or is blocked by autoplay policy returns control to the content immediately. Ads must never be able to prevent someone watching the video they came for.

What's supported

  • VAST 2, 3 and 4 linear creatives
  • Wrapper redirects, with the wrapper's beacons merged into the wrapped ad's
  • Impression, start, quartile, complete and skip tracking
  • Click-through with click tracking
  • skipoffset as a timestamp or a percentage
  • Media-file selection by codec support and player size

Companion banners, non-linear overlays and VPAID are out of scope — VPAID in particular executes third-party code inside your page.
