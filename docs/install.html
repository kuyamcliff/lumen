Installation

Lumen is a custom element. Importing it registers <lumen-player>; there is nothing else to initialize.

npm

npm install @lumen/player
import "@lumen/player";

CDN / script tag

<script type="module" src="https://unpkg.com/@lumen/player"></script>
<lumen-player src="video.mp4"></lumen-player>

Optional dependencies

The core has no required dependencies. These are loaded lazily, only when a page actually plays something that needs them:

PackageNeeded for
hls.jsHLS on non-Safari browsers, and raw MPEG-TS
dashjsMPEG-DASH
mp4boxRecovering truncated or corrupt MP4s
npm install hls.js        # only if you serve HLS
npm install dashjs        # only if you serve DASH
npm install mp4box        # only if you need damaged-file recovery
Script-tag pages: bundler users get these automatically through a dynamic import(). Plain HTML pages should load hls.js via its own script tag — Lumen picks up window.Hls. For mp4box, assign window.MP4Box, since it ships no UMD global build.

Browser support

The last two versions of Chrome, Firefox, Safari and Edge. Remuxed formats (MKV, FLV, MPEG-TS) require Media Source Extensions, which all of those have.
