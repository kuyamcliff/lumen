Plugins

A plugin extends the player without being part of it, using the same public surface an application would.

import type { LumenPlugin } from "@lumen/player";

const watchTime: LumenPlugin = {
  name: "watch-time",
  setup(player) {
    let seconds = 0;
    const off = player.on("timeupdate", () => { seconds += 0.25; });

    // Returning a teardown is optional; it runs on destroy().
    return () => {
      off();
      report(seconds);
    };
  },
};

player.use(watchTime);              // this player
LumenPlayer.use(watchTime);         // every player created afterwards

Ambient mode

import { ambient } from "@lumen/player/plugins/ambient";
player.use(ambient({ spread: 80, intensity: 0.7 }));

Casts a soft glow behind the player, sampled from the video. The frame is drawn to a 16×9 offscreen canvas and blurred back up, which is cheap enough to run continuously. It disables itself under prefers-reduced-motion, and stops if a cross-origin video without CORS taints the canvas.

Design notes

  • Plugins only use the public API. They can't come to depend on internals that are free to change.
  • A failing plugin can't take the player down. setup() is called inside a try/catch; a throw is reported and playback continues.
  • Teardown is optional but encouraged. Anything a plugin subscribes to or appends should be undone in the returned function.
