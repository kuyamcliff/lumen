Errors

player.on("error", ({ code, message, fatal }) => {
  if (!fatal) return;          // non-fatal: recovery in progress
  showMessage(message);        // always human-readable
});
CodeMeaning
NETWORKTransient network failure; retry in progress if non-fatal
DECODEDecode failure, or a dropped undecodable track
SRC_NOT_SUPPORTEDThe browser rejected the source
CONTAINER_UNSUPPORTEDContainer can't be played or remuxed — suggest transcoding
MANIFEST_LOADHLS/DASH manifest failed
UNKNOWNAnything else
A non-fatal error means Lumen is already recovering — reconnecting, or falling back to a remuxer. Only fatal: true means playback has genuinely stopped.
