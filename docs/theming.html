Theming

Every visual token is a CSS custom property with a documented fallback, overridable from page-level CSS without piercing the shadow root.

Built-in themes

<lumen-player theme="dark"></lumen-player>    <!-- default -->
<lumen-player theme="light"></lumen-player>
<lumen-player theme="system"></lumen-player>  <!-- follows prefers-color-scheme -->

Custom skin

lumen-player {
  --lumen-color-accent: #7c5cff;
  --lumen-color-surface: rgba(20, 20, 28, 0.8);
  --lumen-radius: 20px;
  --lumen-font-family: "Inter", sans-serif;
}

Tokens

TokenPurpose
--lumen-color-accentProgress fill, active menu items, focus ring
--lumen-color-surfaceControl bar and menu background
--lumen-color-textIcons and labels
--lumen-color-text-mutedTimecodes, secondary values
--lumen-color-trackUnplayed portion of the scrub bar
--lumen-color-bufferedBuffered portion
--lumen-radiusOuter corner radius
--lumen-aspect-ratioPlayer aspect ratio (or the attribute)
--lumen-object-fitcontain or cover
--lumen-transition-fastHover and press transitions

Shadow parts

For changes tokens can't express, the internals are exposed as parts:

lumen-player::part(controls) { backdrop-filter: blur(20px); }
lumen-player::part(button)   { border-radius: 4px; }

Available parts: root, media, controls, progress, button, menu, captions, poster, spinner, error, big-play.

Reduced motion

All transitions collapse to zero under prefers-reduced-motion: reduce, and ambient mode disables itself entirely.
