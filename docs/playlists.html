Playlists

A playlist advances automatically, and each entry carries its own poster, subtitles, thumbnails and chapters.

player.playlist = [
  {
    src: "episode-1.mkv",
    title: "Episode 1",
    poster: "ep1.jpg",
    chapters: "ep1-chapters.vtt",
    tracks: [{ src: "ep1-en.vtt", label: "English", srclang: "en" }],
  },
  { src: "episode-2.mp4", title: "Episode 2" },
];

Navigation

player.next();
player.previous();
player.playItem(2);
player.playlistIndex;    // -1 before anything is loaded

Next/previous buttons appear in the control bar only when a playlist has more than one entry, and disable at each end.

Events

player.on("playlistchange", ({ items }) => renderQueue(items));
player.on("playlistitemchange", ({ item, index }) => highlight(index));
Setting a playlist loads its first entry but does not start playback — that would be an autoplay the viewer never asked for. Subsequent items play automatically, because by then the viewer has already chosen to watch.

Mixed formats

Entries can be any supported format; each is routed independently, so a queue can freely mix MKV, MP4 and HLS.
