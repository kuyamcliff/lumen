React, Vue & Svelte

Lumen is a Web Component, so it already works in every framework. These wrappers add the parts that framework integration genuinely needs: object props and event binding.

React

import { Lumen } from "@lumen/player/react";

function Player() {
  const ref = useRef(null);

  return (
    <Lumen
      ref={ref}
      src="movie.mkv"
      theme="dark"
      chapters="chapters.vtt"
      tracks={[{ src: "en.vtt", label: "English", srclang: "en" }]}
      onTimeUpdate={({ currentTime }) => setProgress(currentTime)}
      onError={(error) => console.error(error.message)}
    />
  );
}

The ref exposes play(), pause(), seek(), currentTime, duration and qualityLevels, plus player for the full API.

React sets everything as an attribute, so object props like playlist would never arrive, and it has no way to bind non-DOM events. The wrapper assigns properties and subscribes imperatively — which is what makes it feel like ordinary React.

Vue

<script setup>
import { Lumen } from "@lumen/player/vue";
</script>

<template>
  <Lumen
    src="movie.mkv"
    theme="dark"
    :playlist="queue"
    @timeupdate="onProgress"
    @error="onError"
  />
</template>

Svelte

Svelte renders custom elements natively, so the idiomatic integration is an action rather than a wrapper component:

<script>
  import { lumen } from "@lumen/player/svelte";
</script>

<lumen-player
  use:lumen={{
    src: "movie.mkv",
    on: { ready: (p) => (player = p) },
  }}
/>

Without a wrapper

All three are optional. The element works directly:

<lumen-player src="movie.mkv"></lumen-player>
