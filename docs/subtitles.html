Subtitles & chapters

Subtitle tracks are declared exactly like native <video>, but rendered through Lumen's own overlay so styling isn't limited by the browser's caption box.

Adding subtitles

<lumen-player src="video.mp4">
  <track kind="subtitles" src="en.vtt" srclang="en" label="English" default />
  <track kind="subtitles" src="fr.vtt" srclang="fr" label="Français" />
</lumen-player>
player.addTextTrack({ src: "de.vtt", label: "Deutsch", srclang: "de" });
player.textTracks;   // TextTrack[]

Embedded subtitles

MKV files carrying text subtitles (SRT-style or ASS/SSA) have them extracted during remuxing and surfaced as ordinary text tracks — they appear in the same captions menu as external files.

player.on("embeddedtexttrack", ({ track }) => console.log(track.label));

Styling

Viewers can restyle captions from Settings → Captions → Appearance, and their choices persist. The same options are available programmatically:

player.setSubtitlePrefs({
  fontSize: 1.3,            // relative scale
  color: "#ffffff",
  background: "#000000",
  backgroundOpacity: 0.7,
  edge: "outline",          // none | drop-shadow | outline | raised
  position: "bottom",       // bottom | top
  offsetSeconds: 0.5,       // shift cues later, for out-of-sync files
});

Chapters

Chapters come from a WebVTT chapters file and appear three ways: as dividers on the progress bar, as a title while scrubbing, and as a jump menu.

<lumen-player src="video.mp4" chapters="chapters.vtt"></lumen-player>
player.chapters;          // [{ start, end, title }]
player.currentChapter;    // the chapter at the playhead
player.setChapters([{ start: 0, end: 60, title: "Intro" }]);

player.on("chapterchange", ({ chapter }) => console.log(chapter?.title));

Preview thumbnails

<lumen-player src="video.mp4" thumbnails="thumbs.vtt"></lumen-player>

Accepts the WebVTT sprite-sheet format used by Mux, Bunny and similar services (image.jpg#xywh=x,y,w,h).
