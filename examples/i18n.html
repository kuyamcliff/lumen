Translation

Every control label, menu entry and screen-reader announcement resolves through one string table. Switch languages below, then open the settings menu — nothing in the UI is hard-coded to English.

The API

player.setTranslations({
  play: "Lecture",
  pause: "Pause",
  settings: "Réglages",
  quality: "Qualité",
  // Any key you omit falls back to English, so a partial
  // translation degrades gracefully instead of blanking out.
});
