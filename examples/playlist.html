Playlists & chapters

A playlist advances automatically, and each entry carries its own poster, subtitles and chapter markers. Chapters appear as dividers on the progress bar, as titles while scrubbing, and as a jump menu under Settings.

    The API

    player.playlist = [
  { src: "one.mp4", title: "First", poster: "one.jpg", chapters: "one.vtt" },
  { src: "two.mkv", title: "Second", tracks: [{ src: "en.vtt", label: "English", srclang: "en" }] },
];

player.next();
player.previous();
player.playItem(2);

player.on("playlistitemchange", ({ item, index }) => console.log(index, item.title));
player.on("chapterchange", ({ chapter }) => console.log(chapter?.title));
