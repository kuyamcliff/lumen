The rest of the toolkit

Everything a desktop player has and a web player usually doesn't: a ten-band equalizer, picture adjustments, audio and subtitle sync, A → B looping, frame stepping, snapshots, a media information panel, and files opened straight from your machine. Press ? in the player for the full shortcut list.

Equalizer

The ten centre frequencies and all eighteen preset curves are VLC's, running through Web Audio biquad filters. Press q in the player to open the panel and drag the bands. 

player.setEqualizerPreset("rock");
player.audio.set({ preamp: -3, bands: [8, 4.8, -5.6, -8, -3.2, 4, 8.8, 11.2, 11.2, 11.2] });

Audio: boost, delay, stereo mode, normalizer

Volume above 100% for a quietly mastered file, a delay for audio that runs ahead of the picture, channel routing, and dynamic-range compression to even out a film that whispers and then shouts. 

player.audio.set({ boost: 1.8, delayMs: 200, stereo: "mono", normalize: true });

Picture adjustments

Brightness, contrast, saturation, hue and gamma, plus zoom, rotation, flips and a forced aspect ratio — all compositor work, so none of it touches the decoded frames. 

player.setVideoFilters({ brightness: 1.35, saturation: 1.6, gamma: 1.8 });
player.filters.rotate();       // a quarter turn, as VLC's `r` does
player.filters.cycleAspectRatio();

A → B loop, frame stepping, snapshots

Mark two points and the player repeats between them. Step a single frame at a time. Save the frame on screen as a PNG. 

player.cycleAbLoop();          // A, then B, then clear
player.setAbLoop({ start: 12, end: 18 });
player.stepFrame(1);           // and -1 to step back
await player.saveSnapshot();   // downloads a PNG of the current frame

Media information

What is playing, which pipeline is playing it, and how well — resolution, measured frame rate, bitrate, dropped frames and buffer health. Press i, or read the same numbers from the API. 

const info = player.mediaInfo();
// { container: "Matroska (MKV)", engine: "MKV remux", codecs: "vp09.00.31.08,opus",
//   width: 1280, height: 720, frameRate: 30, droppedFrames: 0, … }

Open a file from your machine

Drag a video onto the player, or press o. Subtitles in SRT, ASS/SSA, SubViewer or MicroDVD are converted to WebVTT in the browser — drop a movie and its .srt together and both land where you'd expect.
