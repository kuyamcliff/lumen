Any video format

Lumen identifies a file by its actual bytes, not its extension, and routes it to whatever can play it: straight to the browser when possible, or through a JavaScript demuxer that rebuilds the container as fragmented MP4 for Media Source Extensions. No transcoding, no WASM decoder — the compressed frames are copied across untouched.

Matroska (.mkv)

No browser plays Matroska natively. This one is remuxed to fragmented MP4 on the fly while it downloads.

Progressive MP4

Native playback — the fast path, with no sniffing round trip.

What happens to a format nobody can decode

Containers that genuinely can't be played in a browser (AVI, WMV, FLV) are detected and reported in plain language, rather than failing with a blank player. 

player.on("error", ({ code, message }) => {
  if (code === "CONTAINER_UNSUPPORTED") {
    // e.g. "AVI files can't be played in a browser.
    //       Converting this to MP4 or WebM will fix it."
    showTranscodePrompt(message);
  }
});
